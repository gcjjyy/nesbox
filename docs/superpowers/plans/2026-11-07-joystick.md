# Generic joystick support

**Goal:** Let browser-recognized USB joysticks control NES and arcade games, with saved device-specific mappings.

**Design:** Keep Gamepad API polling and the existing core interface. Preserve standard defaults, union d-pad and stick input, and allow buttons and signed axes to be assigned per device and NES/MAME profile. Store overrides in existing browser settings. Settings shows connection/help, device selection, capture and reset. Keyboard, touch and joystick ownership must not release one another's held buttons. Disconnect, suspension and focus loss release input safely.

**Approaches:** Fixed mappings alone cannot cover generic devices; a native driver is unnecessary for browser-recognized devices. Use browser defaults plus user mappings. User requested generic joystick support; implementation details are defaults chosen by the implementer.

**Tech stack:** Existing React, TypeScript, Gamepad API, Vitest and Playwright; no new dependencies.

## Review focus

- Neutral stick must not cancel d-pad presses.
- Releasing one input source must preserve another source's held input.
- Capture waits for neutral, cancels on disconnect/profile change, and does not feed the running game.
- Saved mappings survive reload and apply only to the selected device/profile.
- Absent or denied Gamepad API must leave keyboard/touch usable.
